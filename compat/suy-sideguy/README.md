# suy-sideguy compatibility shim

This package preserves the historical `suy_sideguy` imports and `suy-*` commands while users
migrate to the canonical `agent-gorgon` distribution, `agent_warden` imports, and
`agent-warden*` commands.

The proposed default window ends with Agent Warden 0.3.x, but not before 2026-10-10. The shim
must not be removed until the repository documentation and preview use only canonical names and
the owner records the flip in the release plan.
